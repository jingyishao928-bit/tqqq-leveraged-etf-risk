# Part 2 中文概述｜TQQQ 的每日重置与历史风险

这一节想回答一个问题：TQQQ 每天追求纳斯达克 100 指数日收益的 3 倍，持有几天以后，为什么结果会和把指数累计收益直接乘以 3 不同？我们先用一个直观的例子说明。假设 QQQ 第一天涨 10%，第二天跌约 9.09%，最后回到起点。理想的每日 3 倍策略第二天会在更高的净值上计入跌幅，两天合计反而亏损 5.45%。

接下来，我们用小组已对齐的 1,983 个交易日收益，比较实际 TQQQ、按每日重置计算的理想 3 倍路径，以及把基准累计收益直接乘以 3 的结果。比较同时使用正式基准纳斯达克 100 价格指数和可交易的 QQQ。历史里有一个明显区别：趋势强时，连续上涨的复利可以放大收益；QQQ 近乎横盘时，波动越大的一组，理想杠杆路径相对直接乘 3 的损耗越明显。样本内 TQQQ 最大回撤为 81.66%，QQQ 为 35.12%。

最后，我们分别定义了固定股数做多和做空 TQQQ 的损失。价格下跌伤害多头，价格上涨伤害空头。这个区分给后续风险分析提供了计算方法：先模拟基准每天怎么走，再逐日重估杠杆策略，最后按头寸分别计算 VaR 和 ES。
